> This project is built for learning cybersecurity concepts by implementing security tools from scratch in Python.

# Security Toolbox

Python로 구현하는 보안 도구 모음입니다.

현재는 Python 기초와 보안 개념을 공부하기 위한 프로젝트이며,
직접 구현을 통해 동작 원리를 이해하는 것을 목표로 합니다.

---

## Features

- Password Generator
- SHA256 Hash Generator
- Base64 Encoder
- Base64 Decoder
- JWT Generator (HS256)
- JWT Decoder
- JWT Signature Verifier

---

## Learning Goals

- Python
- Encoding / Decoding
- Hash
- HMAC
- JWT
- Cryptography Basics
